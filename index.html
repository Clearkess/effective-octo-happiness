FAQ

Common onboarding questions

How do I create an account

Create an account, complete your profile details, and continue to the KYC screen.

How does identity verification work

The KYC page uses a step-based interface for profile, document upload, selfie check, and proof of address.

How do deposits and withdrawals appear

The dashboard links to deposit and withdraw pages with copy address actions and submission-ready forms.

Can I connect a wallet

Yes. You can connect a browser wallet such as MetaMask. A fallback state is shown when no wallet provider is available.
